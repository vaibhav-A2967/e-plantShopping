# e-plantShopping (Paradise Nursery)

Welcome to the **e-plantShopping** application! This project is a responsive online plant shopping platform built with React and Redux Toolkit as part of the full-stack web development coursework.

## Description
Paradise Nursery is an e-commerce website that allows users to explore house plants, view detailed plant information, add items to a shopping cart, modify item quantities, and complete purchases seamlessly.

## Features
* Paradise Nursery landing page with company background and "Get Started" call-to-action.
* Product listing page organized by plant categories (Air Purifying, Aromatic, etc.).
* Fully functional Shopping Cart using Redux Toolkit (`addItem`, `removeItem`, `updateQuantity`).
* Responsive design built with React.

## Technologies Used
* React
* Redux Toolkit
* JavaScript (ES6+)
* HTML5 / CSS3
